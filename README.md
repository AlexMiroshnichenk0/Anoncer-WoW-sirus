# Anoncer-WoW-sirus
WoW addon collection.

## DruidDamageText
Красивый floating-текст урона для друида:

- крупный и читаемый шрифт (`FRIZQT__.TTF` + outline);
- плавное всплытие и затухание;
- цвет урона переключается командой:
  - `/dmgcolor orange`
  - `/dmgcolor yellow`

### Установка
1. Скопируйте папку `DruidDamageText` в `World of Warcraft/Interface/AddOns/`.
2. Перезапустите игру или выполните `/reload`.
3. Играйте за друида, чтобы видеть кастомный текст урона.
